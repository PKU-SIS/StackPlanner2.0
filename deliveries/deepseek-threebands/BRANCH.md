# DeepSeek 三档敲定版本

最初敲定的 DeepSeek 1万／2万／3万三档，未混入千问 v18 或后来的 DS 回归修改。

仓库根目录覆盖为原 1 万档源码；`profiles/10000`、`profiles/20000`、`profiles/30000` 保留三档各自精确的实测代码、查询合同、运行器及文件哈希。不要仅改根目录的字数参数就声称复现另外两档：三档曾有提示词及入口修复差异，应使用对应 profile 的冻结源码和合同。

| 最终目标 | Outline 正文推荐预算 | 默认 |
|---|---|---|
|10000|3000–4000|3500|
|20000|8000–11500|9500|
|30000|13000–16500|15000|

正文预算由 Outline 在推荐区间中选择；最终全文范围、原生验收与正文预算不同。保留研究—初始大纲—固定补研—最终大纲—写作—原生审查；不新增总结、事后压缩、扩写或硬截断。

十四篇结果见 `REPORT.md` 和 `RESULTS.json`，包括完整字数、生成/评分 token、RACE 及失败/续跑历史。这不是同一源码的一轮测试，也不代表两万和三万档始终落在 ±10% 内。

离线完整性检查：在本目录执行 `python3 -B verify.py`。`SHA256SUMS.json` 仅覆盖原归档，不覆盖本次新增的分支说明。

配置模型为 deepseek-flash；实际 API 凭据从自己的环境提供。历史 runner 和 manifest 保留绝对路径及防重复运行检查，迁移需配置原项目依赖、模型/搜索凭据、数据盘输出路径，并创建独立新运行目录；不是直接重跑历史报告的启动命令。backend 的依赖参考保持原归档，harness 明确声明已使用的 markdown-it-py 依赖。未包含 `.env`、完整请求日志、检查点、模型权重或后续 DS 回归代码。
