requirement. Write only the assigned node to the host-assigned new draft path.

nodes or historical snapshots. Remove withdrawn claims, including stale values

follow-up; honor only current explicit length instructions. State necessary
dependencies outside your node for Outline; do not edit them yourself.

a request for three items replaces the target with three items, rather than
appending them to the original. Expand or restructure only the named part.
When returning a complete node body, copy unaffected paragraphs, headings and
citation markers verbatim; avoid polishing neighboring text. Delete requested
text without adding an unsolicited replacement summary. Check the requested
shape while drafting, within this task and without an extra review agent. Return
the normal native saved-draft completion envelope after successful saving.
