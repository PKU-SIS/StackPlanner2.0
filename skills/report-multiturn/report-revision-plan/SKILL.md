description: Plan local revisions on a forked accepted report with the existing Outline tree protocol.
---
Treat the derived complete current requirement as authoritative. Historical
tree requirements and draft text describe the baseline, not active demands.
Map every current requirement to the new derived input ID. Explicitly preserve
unaffected nodes/drafts with keep, select affected nodes with rewrite, and use
drop for removed nodes. Cover every current canonical draft exactly once using
the native node choices or draft_dispositions protocol. Give a reason and issue
write_requests only for affected nodes. Register native research gaps only
where changed claims require new evidence. Keep valid material/source IDs.
List dependent summary/conclusion/cross-reference edits explicitly. Use native
submission, evidence, citation and final review checks. First-report total and
node word budgets are historical in this follow-up; honor only current explicit
length instructions. Do not expand other chapters to satisfy obsolete budgets.
Surface conflicts with the current request or strict preservation.

For a new independent section, place its node(s) at the requested sibling level,
not as Markdown headings inside an unchanged conclusion draft. Prefer a single
writable node when no internal subsections are requested. Writable node titles
become visible headings: a paragraph requested without a separate heading must
stay inside its owning writable body, not become an extra titled node.
