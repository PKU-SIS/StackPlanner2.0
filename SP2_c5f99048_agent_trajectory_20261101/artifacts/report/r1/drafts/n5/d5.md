**Agent2Agent（A2A）协议**是一个开放的 agent 间通信标准，旨在实现不同 AI agent 之间无缝的通信与协作。在使用不同框架、由不同厂商构建的 agent 生态中，A2A 提供了一种通用的 agent 互操作语言[S1]。

从作用方向看，A2A 被定位为**横向（horizontal）互联层**。相比起加深单个 agent 能力、在一个统一架构内运转的纵向连接，A2A 连接的是跨边界的独立 agent——对方可能属于另一个团队、另一个部门或一个合作伙伴组织。你的 agent 需要主动去发现这些 agent、与其协商并交换信息[S4]。这种横向连接不只是简单地向另一个 agent 询问状态更新，而更接近人与人之间的协作方式：agent 之间互相接通、交换上下文，并根据交流结果决定是深入协作，还是被指引到更合适的地方去完成工作[S4]。

技术上，A2A 作为一条通用、去中心化的标准，让相互独立的 agent 能够**发现彼此、委派任务并共享结果**，即便这些 agent 各自通过 MCP 等其他手段获得能力也不受影响[S1]。正是基于这一作用范围，A2A 与 MCP 并不构成竞争——它们解决的是两种不同的问题，并被设计为协同工作的互补协议，而非相互替代[S1]。
