A2A 是一个开放、多厂商治理的协议。它最初由 Google 开发，并捐赠给了 Linux Foundation [S1]。捐赠后，A2A 由一个技术指导委员会（Technical Steering Committee）负责治理与维护，该委员会的成员来自 AWS、Cisco、Google、IBM Research、Microsoft、Salesforce、SAP 和 ServiceNow 等多家厂商，同时得到广泛的合作伙伴社区支持 [S1]。这意味着 A2A 并非由单一公司控制，而是通过多方参与的开放治理机制演进。

在许可证方面，A2A 采用 Apache License 2.0 开源许可发布 [S1]。Apache 2.0 是一种宽松型开源许可证，允许使用者自由使用、修改和分发，并欢迎社区提交贡献，因此降低了集成该协议的门槛，也与其开放源码、跨厂商共建的定位保持一致 [S1]。

综合来看，A2A 由 Google 发起开发、捐赠给 Linux Foundation，由多家厂商代表组成的技术指导委员会共同治理，并以 Apache License 2.0 开源。这种多厂商共治与宽松许可的设计，为协议作为跨企业 Agent 交互的开放标准奠定了基础 [S1]。
