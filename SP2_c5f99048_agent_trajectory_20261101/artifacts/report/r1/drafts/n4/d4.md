Model Context Protocol（MCP）是一个用于将 AI 应用连接到外部系统的**开放标准**，它让 Claude、ChatGPT 等 AI 应用能够接入数据源（如本地文件、数据库）、工具（如搜索引擎、计算器）与工作流（如专门的提示词），从而获取关键信息并执行任务 [S2]。这一连接的标准化意义，常被类比为 AI 应用的 "USB-C 端口"——正如 USB-C 为电子设备互联提供了统一方式，MCP 为 AI 应用接入外部系统提供了一致的标准化通道 [S2]。

从规范层面看，MCP 是一个开放协议，旨在实现 **LLM 应用与外部数据源及工具之间无缝集成** [S3]。这一定义点明了其作用域：它运作在应用程序（尤其是基于 LLM 的应用）与其所需的各类外部资源之间。

在此基础上，A2A 官方文档给出了与 A2A 相对照的定位表述：MCP 用于 **agent 到工具的通信**（agent-to-tool communication），它标准化的是一个 agent 如何连接其工具、API 与资源以获取信息 [S1]。与之相对，A2A 则用于 agent 到 agent 的通信，作为通用、去中心化的标准让相互独立的 agent（包括使用 MCP 的 agent）彼此发现、委派任务并共享结果 [S1]。

综合而言，MCP 标准化的核心在于 **agent 到工具的通信层**——让单个 agent 获取其工作所需的工具、API 与资源。它将"应用与外部系统"的连接统一起来，而把"agent 与 agent"之间的协作交给互补的层次处理，这也为后续分析 A2A 与 MCP 如何分工互补提供了基准。
