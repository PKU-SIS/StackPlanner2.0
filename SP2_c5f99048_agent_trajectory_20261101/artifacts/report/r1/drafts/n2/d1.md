本报告围绕 Google 近期推出的 A2A（Agent2Agent）协议与 MCP（Model Context Protocol）协议展开。根据官方文档的定位，两者同属开放标准：MCP 用于让用户将 agent 连接到工具与数据，而 A2A 则用于让 agent 相互连接并协作[S1]。官方进一步指出，这两种标准相互补充——开发者既可通过 MCP 暴露可移植的工具，也可通过 A2A 暴露可互操作的 agent[S1]。

在此基础上，本报告的研究目标与覆盖范围如下：

- **差异与联系**：详细解释 A2A 与 MCP 在定位、职责与交互对象上的差异，以及两者在构建 agent 应用时形成的互补联系（对应要求 req1）。[S1]
- **A2A 的创新之处**：从协议设计角度阐述 A2A 区别于既有互操作方案（尤其是 MCP 面向工具/数据而非 agent 协作）的创新特性（对应要求 req2）。
- **要解决的具体问题**：阐明 A2A 专门针对的、agent 间可直接互操作与协作所面临的现实问题（对应要求 req3）。

本报告将结论组织为一份带来源引用的研究报告，所有事实性陈述均通过规范的来源标记（以 [S1] 形式）进行可追溯引用（对应要求 req4）。研究范围聚焦于协议本身的定位与设计，不涉及具体实现细节的全面测评。
