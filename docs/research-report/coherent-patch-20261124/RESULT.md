## 修改

条件 Writer Skill 对单句、单元格继续要求最小替换；扩写、重构、压缩则优先先形成完整替换稿，
再把已读原段／原章作为 old_text，一次 patch 新正文。保留有效论点与 source ID，允许重写句子；
超长时重新组织完整受影响段落，避免反复逐词删改。压缩始终以本轮初始正文长度为参照。

这是提示策略，不是限制保存次数的强制条件。原工具、50 次工具容量、原生篇幅阈值、引用／哈希
验证和旧版保护均沿用原实现；首轮默认路径没有变化。
真实执行器脚本回归扩展到短句、段落扩写、章节重组、压缩四种 patch 大小，分别一次保存并
经原生 Finish 交付，逐字核对新正文、旧版全文件 SHA 及其他章节不变。
