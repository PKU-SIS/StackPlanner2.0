## 内容抽查不等于全量事实评分

五份回答都逐条回应三项清单，区分资料原意、报告推导和建议，并披露证据边界。
人工抽查仍发现：original-3有段落编号不精确、把UI/活动格式的导出限制扩大概括为数据/逻辑导出；
paraphrase-2把citations_without_saved_locator为空误用为清单有无直接证据的判断依据，
并把迁移成本的推论表述得过于像资料直接主张。它们不能算严格来源忠实性全部通过。
CHECKS.json保留这些问题；没有独立RACE/FACT或付费评委分数。

`*-answer.md`是模型给程序归档的回答，`*-visible-answer.md`是checkpoint中最后可见回答。
个别用例两者不同，两种文本都保留而不混称。随后补了程序级visible_response.md归档与离线测试，
不追改已冻结运行。完整六轮只读回答也有“四块/三类”的计数措辞不严谨，仍需改善输出精确性。
