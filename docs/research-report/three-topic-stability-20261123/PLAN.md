# 三主题固定稳定性验收

用户批准：3份不同主题现成报告，各测试改一句、改一格、撤销一句但保留单格改动、只读追问，共12项。
只使用现有报告，全部在独立checkout与线程运行；不重生成首轮，不推送、合并、部署或重启服务。

主题：低代码/无代码、离散制造自动化、A2A/MCP协议。前两份取已接受且已有表格的历史版本。
第三份取真实历史归档，路径含脱敏占位符；仅在独立副本重绑路径后，当前原生delivered绑定验证通过。
第三份原稿没有字数合同，沿用原有验收；不为它补造一万字合同，也不降低其他两份原有9000–11000阈值。
原稿无表格，因此先通过正常Writer-first在副本追加对照表，作为基线准备；这次费用单列，不计入12项。

测试前固定实际句子、旧/新单元格、期望完整canonical草稿SHA，以及来源/行号核对依据。
用户query和外部验收分开；外部SHA和评分预期不进入模型。
对每步逐字核验所有canonical草稿，不再只看“改了同一章”：额外改一个单元格也判范围失败。
若一条轨迹首次失败，停止依赖后续；其余主题独立继续，禁止自动改代码/Skill/题目或外层重试。

记录程序交付、精确范围、恢复、语义/来源核对分别的结果；只读回答须逐项区分资料原意和建议，
引用以原文短句和材料行号核对，记录扩大来源范围/错误定位，不能以“有引用”代替正确。
人工只评价和检查，不介入被测请求或修正运行中的输出；介入次数0仍不意味着结果正确。
耗时为每轮运行与记忆回收单调时钟耗时；完整实际token/缓存（输入子集）、所有失败和背景记忆费用均计入。
