## 保留的修改

- 条件加载的 Writer Skill 直接支持现有章节扩写、保存材料补引用、章节内重组与压缩。
  去掉把章节内重组升级到 Outline 的提示限制；章节树变动和新检索仍交中枢协调。
- 小句/单元格用精确片段替换；整章重构允许替换该章正文。无需 JSON 交接或额外分类器。
- 章节读取和保存收据返回原生整篇估计、原篇幅范围、增写余量，以及正文字符数/上次保存比。
  Writer 能在同一次任务内纠正，不需再派 Outline。读取不生成 assembly 或改写 ledger。
- 指导把引用挂到实际支持的论断，重构要调整论证分组而非仅换标题。

没有新增硬拦截、强制审查、工具、模型路由或重试层。也没有删除原生篇幅、引用、哈希、
会话隔离和旧版本保护。反馈无拒绝权：超长文字仍可保存到独立工作副本，但原生交付阈值不变。
这次删减集中在提示中的不必要升级与复杂交接，并非声称删除了大量运行时校验。
