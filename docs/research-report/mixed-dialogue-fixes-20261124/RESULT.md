## 实现

且实际基线回填给 Writer。只有最新用户消息中的 report_dialogue.base_version_id，或开头的

历史 resolved_query 的 mode/base 是旧操作元数据，不能直接变成新一轮指令。

宿主直接 fork/resume 后交给原 Outline，随后沿用树提交、局部 Writer、验收与 Finish。
没有新中枢动作、全能 Update Agent 或外置 LLM 路由。已有 GitAgent 准备好的执行轮不重复 fork；
未绑定首轮和首轮补研 revise 不进入新入口。

条件 Skill 优先区分“在结论之后新增独立章节”和“在原章内新增小标题”。前者增删真实树节点，
后者继续 Writer。正文段落不因存在就另造带标题的写作节点；本批新增根 writable n15 即一个小节。
