## 修改内容

1. 来源读取：在报告正文之前返回material_boundaries，明确material_id/source_id、saved_total_lines、
   saved_line_range与returned_line_ranges；每个摘录另有本地保存/本次展示的说明。
   例如“本地已保存1–147行，本次只展示16–23行”，不再让摘录结束行看起来像文件结束行。
   未展示仍是已保存；未核对不能当不存在。本地保存本身也不保证是网络原文全文。
   普通材料按行读取同步返回保存/展示边界，不增加读取门槛或模型调用。
2. 已失败轮次：既有报告middleware在Central调用前识别当前轮已是failed/cancelled，
   直接返回未完成/取消说明并结束，不再调用Central做恢复选择或重新委派。
   只根据程序已确认的终止状态处理；prepared/executing中的修正、新用户消息、首轮和普通任务保持原流程。
   失败状态与旧accepted head不变，诊断和实际用量记录保留；通知不是新报告交付成功。

条件路由Skill同步解释范围字段。没有新增agent、LLM路由、动作枚举、全局预算或正常路径拒绝规则。
