## 修改

- 报告预检索直接返回完整 Markdown；角色提示、Skill、任务提示和预算收尾提示保持一致。程序构造结果元数据，正文不再依赖长 JSON 转义，也不走 24,000 字符的原始结果恢复截断。
- 复用原有 summary 保存入口；检查正文非空、含真实来源编号，保存后回读确认内容完整。原始 JSON、截断恢复文本、模型输出截断不能冒充成功。
- 格式／引用错误最多修正一次；修正无工具、不搜索、不新增研究轮次。持久标记防止同一委派重复修正；原文、修正输出保留在 diagnostics，失败则关闭本次尝试。
- 补充 read_file/grep 的使用说明和 source/material 编号区别；DeepSeek 搜索词 128 字限制进入工具 schema。

只作用于已绑定报告的预检索 Researcher。普通 Agent、补充研究的 gap 协议、Outline 和 Writer 不改。本轮测试继续使用单体 50 次工具、350 图步、40 次或 token 警戒后收尾；这些预算是测试入口显式配置，跨阶段总 200 次预算未在本轮实现。
