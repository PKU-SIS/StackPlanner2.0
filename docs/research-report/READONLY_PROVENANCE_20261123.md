# 只读溯源收敛与空输出处理

本轮沿用 Writer-first，仅修改显式绑定已接受报告的后续轮。

- `sp_replan` 的 `inspect_version` 默认返回 `provenance`：最近修改的章节、真实标题目录、
  相关来源题名/URL、原 Outline 已接受证据行号与短摘录。可用 `provenance:<node_id>` 指定章节。
- `report_use` 明确是报告的解释，与原资料摘录分开。缺材料/有效行号则明示缺失，不捏造来源意思。
  资料仍可通过 `material:<id>` + start_line/end_line 读取；不强制限制读取次数。
- 每个摘录最多展示8行及2400字符；超长段保留首尾，中间省略和原字符范围显式标注；
  正文长于12000字符时保留开头和结尾。完整原资料、原稿及哈希不变。
- 只读Skill引导先回答相关章节和证据，区分原文、报告推导和建议，缺依据明确说，不为完整出处遍历整篇。
- 空白/长度截断的终止回答保存为独立失败快照及诊断，原始请求、结束原因、可见长度、run和可得用量保留；
  返回明确用户提示，不标记只读回答成功、不推进head、不追加模型重试。正常回答仍可独立归档。
- 任务记忆 after_agent 仅回传此显式后续轮的提示；首轮、普通功能原路径保持。
