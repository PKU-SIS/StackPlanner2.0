## 暴露的问题

### 新附件尚未接入轻量 Writer

真实上传端点返回成功，new-material.md 文件存在。附件明确标为测试合成资料，内容是内部建议，
不是伪造实证事实。提交使用与前端一致的 additional_kwargs.files（filename、size、path、status）。
中枢却选择 local_edit。该 Writer 只有查章节、读章节、精确替换、读已保存报告材料四种工具，
不能读取新 uploads 文件，也不能登记材料。它看到文件名与大纲、读不到三条建议正文，最终报告
“No changes saved”，本轮 failed，没有发布新版本。上传成功不能当作报告已使用附件。
这次验证的是“新附件补已有章节”的常见路径，不代表其他显式复杂路由下的附件功能全部不可用。

### 新来源引用格式未接入最终文献

新稿有 87 处 [S204:15-21] 一类带行号的标记，共使用 S204、S205、S225、S226、S244、S246。
这些 ID 及材料实际存在，但 CITATION_RE 只识别 [S204]／配对转义形式，未识别带行号语法。
因此新增正文中的原始标记没有转为编号，新来源全部未进入 final_report.citation_numbering 和
最终来源列表。新来源检索／保存、章节生成确已发生，但“据新资料写作并有正式引用”的交付合同
未全面通过。这是来源接入和引用格式兼容问题，不是本轮对事实正确率做了完整评分。
原始交付完整封存，没有原地修改；本次不把最低验收通过当作引用链已经完整。
