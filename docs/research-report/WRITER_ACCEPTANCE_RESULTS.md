## 修改

- Writer Skill / 提示词：完成有依据的正文，省略无支撑的附加细节；节点规格是指导，不是事实证据，缺少非必要细节不要求 partial 或 node_feedback。
- Hook：指定路径已有可读、非空正文时，不因 partial/blocked、evidence_gaps 或 node_feedback 拒绝；不新增内部状态字段或缺口复核。
- 保留错误路径、空文件、重复标题、真实技术截断等原有校验；纯反馈且没有正文仍沿现有路径。
