## 改动

在已绑定成稿的独立副本激活阶段，程序将最新 HumanMessage.files 声明的可读附件复制进
原生报告材料库，复用 _save_material_text 的源文保存、读回验证、SHA 和材料编号，不调用模型。
来源标记 user_upload，保留文件名、当前消息／输入 ID、原上传位置、内容位置与内容 SHA；
不伪造外部网址。Writer 通过 report_local_edit.uploaded_materials 得到 ID，使用原有
report_read_material 读取并引用，没有增加工具或给它开放任意文件访问。

读取限定当前 owner/thread 的声明文件，逐级目录描述符与 O_NOFOLLOW 防止符号链接跳转。
普通 UTF-8 文本按原字节保存；PDF／Office 只复用已经生成的同名 Markdown 转换结果，
不在本路径运行转换器／OCR，不保证转换文本等同原文件全文。转换的 upstream_truncation=unknown。
不可读取的附件给出 unavailable 提示，不凭文件名编造内容，也不直接中断无关改稿。
同文件同内容重复登记复用已有 source/material，材料独立复制，不依赖后续仍保留原上传文件。

共享来源标记识别新增 [S204:15-21]／转义写法。组装、已知来源校验、只读来源提取和最终展示
共用该识别器：source_id 仍为 S204，交付呈现正常编号 [32] 并加入文献，canonical 草稿保留行号。
未知 source ID 继续按既有规则拒绝；语法识别不代表行范围或论断事实已被独立核验。
普通标记、转义数学内容和已批准旧 source_table 的输出保持兼容，不回写历史交付。
首轮不增加模型步骤、路由、工具、提示或预算；现有有效引用语法的行为不变。
