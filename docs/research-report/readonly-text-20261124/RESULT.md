## 修改

原 `draft:<node_id>` / `report` 读取将完整 turn 放在正文前，包含长 resolved_query、
原始需求与历史元数据。工具输出被通用预算截成预览时，真正需要的正文可能排在预览之外。
回归种子可复现约 63,505 字符的返回，虽只是读取一句正文。

本次没有增加 Agent、分类器、重试或验收关卡：

- 新增 `inspect_version view="sections"`，只列当前 canonical 章节 ID 与实际标题。
- 正文、资料、树等数据视图使用精简版本头；`requirements`、`manifest` 仍保留完整元数据。
- `draft:<node_id>` 与 `report` 支持 start_line/end_line，保留原文行尾、完整正文 SHA、
  返回行范围及截断说明。无范围参数时仍沿用原完整读取和 50,000 字符上限。
- 条件路由 Skill 区分“照录报告原文”与“检查资料支持”：前者直接读目录/草稿，后者保留 provenance。
  已知节点或已读且未变的正文可复用，不要求每次重复查目录。

所有读取都验证已接受版本及快照绑定；只读，不准备工作副本、不 resume、不发布。
首轮默认 Skill、工具、预算、调度及原生证据/引用/篇幅验收没有改变。
